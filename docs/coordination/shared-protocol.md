# gRPC 契约变更登记（shared-protocol.md）

> Java（Mu-mirror-B，proto 在 `src/main/proto/`）与 Python（Mu-mirror-AI，proto 在 `proto/`）的契约同步点。
> **规则**：任何一方改动 proto / LlmConfig / 枚举语义，必须在此追加一行登记。对方开工前必读本文件。
> 历史踩坑：proto 不同步会导致字段错位（api_key/base_url/model 串位）。Java 改 proto 后 Python 必须重跑 `generate_proto.py`。
